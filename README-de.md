**White Virus** ist eine interaktive Präsentation rund um die Ästhetik des „digitalen Virus". Durch Windows-Fehlermeldungen, Bildschirmflackern und Popup-Bombardements wird ein eindrucksvolles digitales Narrativ-Erlebnis geschaffen.
