**White Virus** là một bài thuyết trình tương tác xoay quanh khái niệm thẩm mỹ "virus kỹ thuật số". Thông qua các cửa sổ lỗi Windows, nhấp nháy màn hình và bom nổi cửa sổ, nó tạo ra một trải nghiệm kể chuyện kỹ thuật số có tác động mạnh mẽ.
