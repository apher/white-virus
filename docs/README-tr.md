**White Virus**, "dijital virüs" estetiği etrafında şekillenen interaktif bir sunumdur. Windows hata pencereleri, ekran titremeleri ve açılır pencere bombardımanı gibi görsel öğeler aracılığıyla yüksek etkili bir dijital anlatı deneyimi oluşturur.
