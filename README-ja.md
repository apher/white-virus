**White ウイルス** は「デジタルウイルス」美学をコンセプトにしたインタラクティブな演示作品。Windows エラーウィンドウ、画面チカチカ、ポップアップ攻撃などの視覚要素を通じて、圧倒的なデジタルナラティブ体験を構築します。
