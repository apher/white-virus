**White Virus** เป็นงานนำเสนอแบบโต้ตอบที่มีแนวคิดหลักเกี่ยวกับสุนทรียศาสตร์ของ "ไวรัสดิจิทัล" ผ่านหน้าต่างข้อผิดพลาดของ Windows การกระพริบของหน้าจอ และการโจมตีแบบป๊อปอัพ สร้างประสบการณ์การเล่าเรื่องดิจิทัลที่มีผลกระทบสูง
