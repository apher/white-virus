# White 病毒 · White Virus

> 一个关于数字病毒美学的交互式 PPSX 演示

**White 病毒** 是一个以"数字病毒"为核心概念的交互式演示作品。通过 Windows 报错窗口、屏幕闪烁、弹窗轰炸等视觉元素，构建极具冲击力的数字叙事体验。
