**White 病毒** 是孩子（APher）的课外兴趣项目——一个以"数字病毒"为核心概念的交互式演示作品。通过 Windows 报错窗口、屏幕闪烁、弹窗轰炸等视觉元素，构建极具冲击力的数字叙事体验。

## 📂 项目内容

| 文件 | 说明 |
|------|------|
| `white病毒.ppsx` | 原始幻灯片放映文件（PowerPoint Show） |

## 🚀 快速开始

### ⬇️ 直接下载

**点击下载** → [white病毒.ppsx](https://github.com/apher/white-virus/releases/download/v1.0/white.ppsx)

### 直接播放 PPSX
1. 下载 `white病毒.ppsx`
